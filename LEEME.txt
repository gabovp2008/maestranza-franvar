Para revisar:
1. Descomprime el ZIP.
2. Abre index.html en Chrome, Edge o Firefox.

Para editar:
Abre index.html con Bloc de notas o Visual Studio Code.

Publicar gratis con GitHub Pages:
1. Crea una cuenta en https://github.com/
2. Crea un repositorio publico llamado usuario.github.io (reemplaza usuario por tu usuario).
3. Sube index.html a la raiz del repositorio.
4. En Settings > Pages, selecciona Deploy from a branch, rama main y carpeta /(root).
5. Tu sitio se publicara en https://usuario.github.io

Nota: el formulario de consulta usa mailto y abre la aplicacion de correo del visitante. El enlace de WhatsApp abre una conversacion con el numero indicado.
